EXAONE-4.0-1.2B 기반 LLM FP8 양자화 및 경량화 최적화

LG Aimers 8기 해커톤 | 팀 프로젝트 (조장) | 2026.02
Python PyTorch Hugging Face llmcompressor FP8 Quantization vLLM
  • 문제 정의: On-Device 및 제한된 GPU 환경에서 대규모 언어 모델(LLM)을 구동할 때 발생하는 메모리 점유율과 응답 지연(Latency) 문제를 해결하고자 했습니다. 전체 레이어에 일괄 양자화를 적용할 경우 발생하는 급격한 추론 정확도 하락을 방지하면서, 모델 크기와 추론 속도, 성능 간의 최적 균형점을 도출하는 것을 목표로 설정했습니다.
  • 역할 (팀 조장) 및 핵심 구현: 팀 리더로서 전체 실험 로드맵 수립, 팀원 간 역할 분담 및 실험 결과 통합 조율을 총괄했으며, 핵심 양자화 파이프라인을 직접 설계·구현했습니다.
    • FP8 One-shot PTQ 및 핵심 레이어 보호 전략: llmcompressor를 활용해 Linear 레이어에 FP8 양자화를 적용하되, 성능에 민감한 입출력층(embed_tokens, lm_head)과 초기·후반부 트랜스포머 블록 4개(layers.0, 1, 22, 23)를 양자화에서 제외(ignore)하여 정확도 저하를 방어했습니다.
    • 평가 환경 맞춤형 캘리브레이션(Calibration): LGAI-EXAONE/MANTA-1M 데이터셋에서 구간별 균등 샘플링으로 128개 데이터를 추출하고, 실제 vLLM 평가 파이프라인과 동일하게 add_generation_prompt=True 챗 템플릿을 적용해 양자화 분포 왜곡을 최소화했습니다.
    • 메모리 및 서빙 포맷 최적화: 대용량 데이터셋 처리 시 가비지 컬렉션(gc.collect())으로 메모리 누수를 방지하고, vLLM 추론 호환성을 위해 safetensors 표준 포맷으로 가중치를 직렬화했습니다.
  • 결과 및 배운 점: 레이어별 민감도 분석과 평가 환경 맞춤형 전처리를 결합하여, 제한된 하드웨어 자원(NVIDIA L4 GPU, 추론 시간 20분 이내) 조건에서 안정적인 추론 속도와 벤치마크 성능을 동시에 확보한 경량화 모델을 최종 제출했습니다. 이 과정을 통해 이론적 압축 기법을 실제 추론 엔진(vLLM) 환경에 맞게 최적화하는 실전 엔지니어링 역량을 길렀습니다.
